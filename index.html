Projects

Hall Rental System

A web-based system developed to simplify hall reservation and booking management processes. The system allows users to check hall availability, submit booking requests, and manage reservation details efficiently.

The admin module provides features for managing booking approvals, hall schedules, and user records. The system was developed using HTML, CSS, PHP, and MySQL with a focus on usability, responsive design, and efficient data management.

In addition, the system includes a dashboard that visualizes booking data through graphs and charts for easier monitoring and analysis. It is also capable of automatically calculating total hall rental income on a monthly and yearly basis to assist in financial tracking and reporting.

Dunia Isomer

Dunia Isomer is a Mobile Game-Based Learning Application developed as a Final Year Project to assist students in understanding the concept of isomerism in Chemistry through interactive and engaging gameplay.

The application integrates educational content with game-based learning elements such as drag-and-drop activities, quizzes, and progressive challenge levels to create a more interactive learning experience. The game was designed to simplify abstract chemistry concepts and improve students’ engagement during the learning process.

Usability and effectiveness testing were conducted among students at SMK P Kapar to evaluate the application’s user experience and learning impact. The findings showed positive feedback in terms of usability and engagement. However, the effectiveness results were limited due to the time-consuming nature of the application during the testing session.

In addition, the testing process may contain sampling bias as the evaluation was conducted only among female students since the selected school consists exclusively of female students. Despite these limitations, the project demonstrates the potential of mobile game-based learning as an alternative educational tool for Chemistry subjects.

3D Modelling (Blender Project)

A series of 3D models were created using Blender to demonstrate fundamental skills in 3D modelling, object design, and digital visualization. The project includes the development of multiple objects such as a character model, a box, a bullet box, and a house structure.

Each model was designed using basic to intermediate modelling techniques, including mesh editing, extrusion, scaling, and shaping to achieve accurate forms and proportions. Attention was given to object detail and structure to ensure each model is visually clear and suitable for use in a 3D environment.

The character model focuses on basic humanoid structure design, while the box and bullet box demonstrate simple hard-surface modelling techniques. The house model showcases architectural modelling principles, including walls, roof structure, and spatial layout.

Overall, this project highlights the application of Blender in creating diverse 3D assets and strengthens understanding of modelling workflows used in game development and animation environments. These models were also implemented in the educational game environment Dunia Isomer to support interactive learning and enhance the visual experience within the game.

Dengue Defender

Dengue Defender is a 2D educational game developed to raise awareness about dengue fever and promote effective prevention methods through immersive, level-based gameplay.

The game is structured into three progressive levels, each designed with different environments and learning objectives. In Level 1, the setting is a pharmacy where players are introduced to the correct medication and basic treatment knowledge for dengue patients.

In Level 2, the game transitions to a residential outdoor environment where players must identify and clean mosquito breeding sites. This level focuses on reinforcing awareness of prevention practices in everyday surroundings.

In Level 3, players enter an action-based outdoor setting where they use spraying tools to eliminate flying mosquitoes. To enhance gameplay strategy and engagement, players can also restore health by collecting vaccines when hit by mosquitoes.

Overall, the game combines educational content with interactive mechanics to improve understanding of dengue prevention while maintaining an engaging and enjoyable learning experience.

Online vs Physical Shopping

A machine learning-based predictive analysis project aimed at identifying user preferences between online and physical shopping.

The study was conducted using a dataset of over 500 respondent entries to analyze consumer behavior and determine shopping preferences. A Logistic Regression (LR) model was applied to classify user preferences, with K-Fold cross-validation used to improve and evaluate model accuracy.

The project also involved data preprocessing and cleaning to ensure dataset quality and reliability for analysis. Comparative model performance was evaluated to identify the most effective approach.

In addition, the findings were visualized using graphs and charts to present trends and insights in a clear and interpretable manner.

2D Pendulum Clock (OpenGL Animation Outcome)

The final outcome of this project is a 2D pendulum clock developed using OpenGL, featuring a fully constructed clock structure built from basic output primitives such as polygons, lines, and shapes. The design successfully simulates a traditional standing pendulum clock with clear visual components including the clock face, body structure, and pendulum system.

The pendulum is animated to swing smoothly between the left and right directions, demonstrating the implementation of transformation and motion principles in computer graphics. This interaction reflects the real-world physics behavior of a pendulum, where continuous oscillation is achieved through programmed animation logic.

The visual appearance is enhanced using solid color filling and shading techniques to improve clarity and realism. Overall, the project demonstrates the effective use of 2D graphics programming to create an interactive and visually structured pendulum clock animation.
